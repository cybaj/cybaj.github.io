# wiki

Wikipedia, any language edition.

## Good for

- Orienting on a topic you do not know yet — what it is, what it is called,
  what the neighbouring concepts are
- Settled terminology, especially the Korean term for something you only know
  in English, or the reverse
- Finding primary sources. An article's References section is a curated list of
  what to read next; harvest those with the `web` source

## Not good for

- Citing as the authority. Cite what Wikipedia cites. An encyclopedia is where
  you find the source, not the source itself.
- Contentious topics, where the article reflects whoever edited it last
- Anything recent enough to still be churning — a week-old event has a week-old
  article, edited hourly
- Assuming the Korean and English articles agree. They are separate documents
  written by different people; see `usage.md`.

## Requirements

None. No API key, no account.

# web

Any publicly reachable URL: official documentation, blog posts, articles,
specifications.

## Good for

- Primary documentation, cited directly
- A specific article you already know you want
- Checking current behaviour of a tool or API

## Not good for

- Anything behind a login or paywall
- Discovery. This source fetches a URL you already have; finding candidates is
  a search engine's job, and the URLs it returns are what you fetch here.
- Content that changes frequently — record `retrieved` and re-check before
  relying on it later.

## Requirements

None. No API key, no installation.

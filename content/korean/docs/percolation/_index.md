다공성 물질 위에 물을 부으면 바닥까지 스며들까?

이 질문은 1957년 Broadbent 와 Hammersley 가 수학 문헌에 처음 들여왔고
([Percolation theory](https://en.wikipedia.org/w/index.php?oldid=1362426482)),
그 뒤로 확률론과 통계물리의 한 분야가 되었습니다.

## 답이 재미있는 이유

각 통로가 확률 {{< katex >}}p{{< /katex >}} 로 독립하게 열려 있다고
하겠습니다. 위에서 아래까지 이어지는 길이 있을 확률은
{{< katex >}}p{{< /katex >}} 가 커질수록 당연히 커집니다. 여기까지는 놀랍지
않습니다.

눈여겨볼 것은 어떻게 커지는가입니다. 완만한 곡선이 아니라, 어떤 값 근처에서
거의 0 이던 것이 거의 1 로 급격히 올라갑니다. 격자가 100 칸만 되어도 눈에
보일 만큼 가파릅니다.

무한 격자에서 이 현상은 아예 불연속이 됩니다. 원점이 속한 클러스터가 무한할
확률

{{< katex display=true >}}
\theta(p) = \mathbb{P}_p\big( |C(0)| = \infty \big)
{{< /katex >}}

를 생각하면, 어떤 {{< katex >}}p_c{{< /katex >}} 가 존재해서

{{< katex display=true >}}
\theta(p) = 0 \quad (p < p_c), \qquad \theta(p) > 0 \quad (p > p_c)
{{< /katex >}}

가 됩니다. 이 {{< katex >}}p_c{{< /katex >}} 가 임계 확률이고, 이어지는
글은 모두 이 하나를 다른 각도에서 보는 것입니다.

## 어디까지 계산할 수 있는가

{{< katex >}}p_c{{< /katex >}} 가 존재한다는 것은 증명되지만, 값을 구하는
것은 완전히 다른 문제입니다. 여기서 실제로 유도해 볼 것은 다음 셋입니다.

- 1차원에서 {{< katex >}}p_c = 1{{< /katex >}} — 한 줄 계산
- 2차원에서 {{< katex >}}p_c \ge 1/3{{< /katex >}} — 경로 세기
- 베테 격자에서 {{< katex >}}p_c = 1/(z-1){{< /katex >}} — 분기 과정

유도되지 않는 것도 함께 보겠습니다. 2차원 사이트 침투의
{{< katex >}}p_c{{< /katex >}} 는 소수점 여덟 자리까지 알려져 있지만 해석적
유도가 없습니다.

## 읽는 순서

- **모델** — 무엇을 확률적으로 열 것인가, 그리고 {{< katex >}}\theta{{< /katex >}} 가 왜 증가하는가
- **임계 확률** — {{< katex >}}p_c{{< /katex >}} 의 존재 증명과 알려진 값들
- **어디에 쓰이는가** — 네트워크와 재료, 분기 과정으로 얻는 정확한 값

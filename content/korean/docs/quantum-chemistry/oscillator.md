[상자 속 입자]({{< ref "particle-in-a-box.md" >}})의 벽은 편리했지만
정직하지는 않았습니다. 무한히 높고 두께가 0 인 벽은 자연에 없기 때문입니다.
이제 훨씬 현실적인 퍼텐셜을 다루겠습니다. 이 퍼텐셜은 단지 현실적인 정도가
아니라 거의 모든 결합에 적용되는 퍼텐셜입니다.
(개인 노트: 4장 진동 운동: 조화 진동자)

## 왜 하필 포물선인가

먼저 이 질문에 답해 두는 것이 좋겠습니다. 조화 진동자는
{{< katex >}}V = \tfrac12 kx^2{{< /katex >}} 이라는 특정한 퍼텐셜을 다루는데,
왜 이 하나가 그렇게 중요할까요.

평형점 근처에서는 모든 퍼텐셜이 포물선이기 때문입니다.

임의의 퍼텐셜 {{< katex >}}V(x){{< /katex >}} 를 평형 위치
{{< katex >}}x_0{{< /katex >}} 주위에서 테일러 전개해 보겠습니다.

{{< katex display=true >}}
V(x) = V(x_0) + V'(x_0)(x - x_0) + \tfrac{1}{2}V''(x_0)(x-x_0)^2 + \cdots
{{< /katex >}}

여기서 두 항을 지울 수 있습니다. 첫째 항
{{< katex >}}V(x_0){{< /katex >}} 는 에너지의 기준점일 뿐이므로 0 으로 잡으면
됩니다. 둘째 항은 평형점의 정의상 0 입니다. 평형이란 힘이 0 이라는 뜻이고
{{< katex >}}F = -V'{{< /katex >}} 이므로
{{< katex >}}V'(x_0) = 0{{< /katex >}} 이기 때문입니다.

남는 첫 항은 2차항입니다.

{{< katex display=true >}}
V(x) \approx \tfrac{1}{2}V''(x_0)\,(x-x_0)^2 \equiv \tfrac{1}{2}kx^2
{{< /katex >}}

{{< katex >}}k = V''(x_0){{< /katex >}} 로 놓으면 정확히 조화 퍼텐셜입니다.

그러므로 어떤 결합이든 어떤 분자든, 평형에서 조금만 벗어나는 진동이라면 조화
진동자로 근사됩니다. 퍼텐셜의 자세한 모양은 알 필요가 없고 최소점에서의 곡률
하나만 알면 됩니다. 조화 진동자가 물리학과 화학 전체에서 반복해 등장하는
이유입니다.

물론 크게 벗어나면 3차항 이상이 살아나고, 그때부터 비조화성(anharmonicity)이
나타나 결합이 끊어질 수 있게 됩니다. 조화 진동자에서는 결합이 끊어지지
않는데, 포물선이 위로 무한히 올라가기만 하기 때문입니다.

## 고전적인 그림

Hooke 법칙은

{{< katex display=true >}}
F = -kx
{{< /katex >}}

이고, 퍼텐셜은 힘을 적분해 얻습니다.

{{< katex display=true >}}
V(x) = -\int_0^x F\,dx' = \int_0^x kx'\,dx' = \tfrac{1}{2}kx^2
{{< /katex >}}

고전역학에서 이 계는 각진동수

{{< katex display=true >}}
\omega = \sqrt{\frac{k}{m}}
\qquad\text{또는}\qquad
\nu = \frac{1}{2\pi}\sqrt{\frac{k}{m}}
{{< /katex >}}

로 단순 조화 운동을 합니다. 여기서 중요한 것은 진동수가 진폭과 무관하다는
점입니다. 세게 튕기든 약하게 튕기든 같은 진동수로 떨립니다. 그리고 고전적으로는
에너지가 진폭으로 정해지므로 어떤 값이든 될 수 있고, 정지 상태
({{< katex >}}E=0{{< /katex >}})도 당연히 허용됩니다.

양자역학이 바꾸는 것이 정확히 이 두 가지입니다.

## Schrödinger 방정식과 경계조건

퍼텐셜을 넣으면

{{< katex display=true >}}
\boxed{\;-\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2} + \tfrac{1}{2}kx^2\psi = E\psi\;}
{{< /katex >}}

입니다. 상자와 달리 벽이 없는데, 경계조건은 어디서 올까요.

퍼텐셜이 양쪽으로 무한히 커진다는 사실에서 옵니다. 아주 먼 곳에서는
{{< katex >}}V(x){{< /katex >}} 가 어떤 유한한 에너지
{{< katex >}}E{{< /katex >}} 보다도 커지므로, 입자가 그곳에서 발견될 확률은
0 으로 가야 합니다.

{{< katex display=true >}}
\boxed{\;\psi(x) \to 0 \qquad (x \to \pm\infty)\;}
{{< /katex >}}

이것이 조건입니다. 상자에서는 "벽에서 정확히 0", 여기서는 "무한히 멀리서 0
으로 수렴" 인 셈이니 형태는 다르지만 하는 일은 같습니다. 이 조건을 만족하는
해가 특정 {{< katex >}}E{{< /katex >}} 에서만 존재하고, 그것이 양자화를
만듭니다.

### 상자와 다른 점 하나

파동함수의 끝이 다릅니다. 상자에서는 퍼텐셜이 벽에서 갑자기 무한대가 되므로
파동함수도 거기서 뚝 끊겨 0 이 됩니다. 조화 진동자에서는 퍼텐셜이
{{< katex >}}x^2{{< /katex >}} 으로 서서히 올라가므로 파동함수도 서서히
줄어들어 0 에 수렴합니다.

| 모형 | 퍼텐셜 | 파동함수의 끝 |
|---|---|---|
| 상자 속 입자 | 벽에서 갑자기 무한대 | 벽에서 정확히 0 |
| 조화 진동자 | {{< katex >}}x^2{{< /katex >}} 으로 점진적 증가 | 서서히 0 으로 수렴 |

이 "서서히" 가 나중에 흥미로운 결과를 낳습니다. 고전적으로 갈 수 없는 곳에도
확률이 조금 남는다는 것인데, 아래에서 다시 보겠습니다.

## 에너지 준위

방정식을 풀면 (Hermite 방정식으로 바뀌고, 해가 유한하게 남을 조건에서)

{{< katex display=true >}}
\boxed{\;E_v = \left(v + \tfrac{1}{2}\right)\hbar\omega,
\qquad v = 0, 1, 2, \dots\;}
{{< /katex >}}

가 나옵니다. {{< katex >}}v{{< /katex >}} 를 진동 양자수라 합니다.

상자와 비교하면 두 가지가 확연히 다릅니다.

첫째, 준위 간격이 일정합니다.

{{< katex display=true >}}
\Delta E = E_{v+1} - E_v = \hbar\omega
{{< /katex >}}

{{< katex >}}v{{< /katex >}} 가 얼마든 간격이 같습니다. 상자에서는
{{< katex >}}E \propto n^2{{< /katex >}} 이라 위로 갈수록 벌어졌던 것과
대조적입니다. 이 차이는 분광학에서 곧바로 드러나서, 진동 스펙트럼에는 모든
전이가 같은 에너지를 갖는 탓에 굵은 선이 하나만 나타납니다. (실제로는
비조화성 때문에 위로 갈수록 간격이 조금씩 좁아지고, 그래서 배진동 overtone 이
약하게 보입니다.)

둘째, 바닥 상태가 {{< katex >}}v = 0{{< /katex >}} 이고 에너지가 0 이
아닙니다.

{{< katex display=true >}}
E_0 = \tfrac{1}{2}\hbar\omega
{{< /katex >}}

## 영점에너지, 다시

상자에서와 같은 일이 벌어졌습니다. 최저 에너지가 0 이 아니며, 이유도
같습니다.

만약 {{< katex >}}E = 0{{< /katex >}} 이라면 운동에너지도 0 이고 퍼텐셜
에너지도 0 이어야 합니다. 퍼텐셜이 0 이라는 것은
{{< katex >}}x = 0{{< /katex >}} 에 정확히 멈춰 있다는 뜻이고, 운동에너지가
0 이라는 것은 {{< katex >}}p = 0{{< /katex >}} 이라는 뜻입니다. 위치와 운동량이
동시에 확정되는 셈이니 불확정성 원리를 정면으로 어깁니다.

{{< katex display=true >}}
\Delta x\,\Delta p \ge \frac{\hbar}{2}
{{< /katex >}}

그래서 결합은 절대영도에서도 떨림을 멈추지 않습니다. 이것은 이론적 장식이
아니라 실제로 측정되는 양입니다. 동위원소 치환으로 영점에너지가 바뀌면 반응
속도가 달라지고(동위원소 효과), 결합 해리 에너지도 달라집니다.

## 파동함수의 모양

해의 일반형은 두 조각의 곱입니다.

{{< katex display=true >}}
\psi_v(x) \propto H_v(y)\,e^{-y^2/2},
\qquad y = \sqrt{\frac{m\omega}{\hbar}}\,x
{{< /katex >}}

각 조각이 하는 일이 다릅니다.

Gauss 함수 {{< katex >}}e^{-y^2/2}{{< /katex >}} 는 경계조건을 담당합니다.
{{< katex >}}|y|{{< /katex >}} 가 커질수록 빠르게 0 으로 잦아들므로
{{< katex >}}\psi \to 0{{< /katex >}} 이 저절로 보장되며, 모든 상태가 이
포락선을 공유합니다.

Hermite 다항식 {{< katex >}}H_v(y){{< /katex >}} 는 마디를 담당합니다.

{{< katex display=true >}}
H_0(y) = 1, \qquad H_1(y) = 2y, \qquad H_2(y) = 4y^2 - 2, \quad \dots
{{< /katex >}}

{{< katex >}}v{{< /katex >}} 차 다항식이므로 근이
{{< katex >}}v{{< /katex >}} 개입니다. 따라서

{{< katex display=true >}}
\text{마디 수} = v
{{< /katex >}}

상자에서는 {{< katex >}}n-1{{< /katex >}} 이었는데 여기서는
{{< katex >}}v{{< /katex >}} 입니다. 세는 방식이 다를 뿐 원리는 같습니다. 바닥
상태는 마디가 없고, 올라갈수록 하나씩 늘며, 마디가 많을수록 곡률이 크고, 곡률이
크면 에너지가 높습니다.
[상자 속 입자]({{< ref "particle-in-a-box.md" >}})의 "곡률이 곧 운동에너지" 가
그대로 적용되는 것입니다.

바닥 상태는 다항식이 상수이므로 순수한 Gauss 함수입니다.

{{< katex display=true >}}
\psi_0(x) \propto e^{-m\omega x^2/2\hbar}
{{< /katex >}}

가운데가 가장 높은 종 모양입니다. 고전적 직관과 정반대라는 점이 중요합니다.
고전적인 진동자는 전환점 근처에서 가장 느리므로 그곳에 있을 확률이 가장 높고
가운데를 가장 빨리 지나가는 반면, 양자적 바닥 상태는 가운데에 있을 확률이 가장
큽니다.

## 대응원리와 금지된 영역

그렇다면 고전적 그림은 언제 돌아올까요. {{< katex >}}v{{< /katex >}} 를
키우면 됩니다. {{< katex >}}v{{< /katex >}} 가 커질수록
{{< katex >}}|\psi_v|^2{{< /katex >}} 의 마루들이 바깥쪽에서 높아지고 가운데는
상대적으로 낮아져서, 전체 포락선이 고전적 확률분포(전환점에서 최대)에
가까워집니다. 상자에서 본 대응원리가 여기서도 성립하는 것입니다.

한 가지가 더 있습니다. 고전적으로 입자는
{{< katex >}}V(x) > E{{< /katex >}} 인 영역에 들어갈 수 없습니다. 운동에너지가
음수가 되어야 하기 때문이고, 전환점이 그 경계입니다.

그런데 양자 파동함수는 전환점 바깥에서도 0 이 아니어서 Gauss 꼬리가
남아 있습니다.

{{< katex display=true >}}
|\psi(x)|^2 \neq 0 \qquad (V(x) > E \text{ 인 영역에서도})
{{< /katex >}}

입자가 고전적으로 금지된 영역에서 발견될 확률이 0 이 아니라는 뜻입니다. 바닥
상태에서 이 확률은 약 16% 로 무시할 만한 크기가 아니며, 터널링(tunneling)의
씨앗이 됩니다. 파동함수가 장벽 안으로 스며들 수 있다면, 장벽이 충분히 얇을 때
반대편으로 새어 나갈 수도 있기 때문입니다.

퍼텐셜이 벽처럼 갑자기 무한대가 되지 않고 서서히 올라가기 때문에 생기는
일입니다. 앞에서 "서서히" 를 짚어 둔 이유가 여기에 있습니다.

## 분자에 적용하기: 환산질량

지금까지는 질량 {{< katex >}}m{{< /katex >}} 인 입자 하나를 다뤘습니다.
그런데 이원자 분자에서는 원자 둘이 서로에 대해 움직입니다. 벽에 고정된
용수철이 아니라 양 끝에 추가 달린 용수철인 셈입니다.

이 두 물체 문제는 상대 좌표로 바꾸면 한 물체 문제가 되는데, 그때 질량 자리에
들어가는 것이 환산질량입니다.

{{< katex display=true >}}
\boxed{\;\mu = \frac{m_1m_2}{m_1+m_2}\;}
\qquad\text{또는}\qquad
\frac{1}{\mu} = \frac{1}{m_1} + \frac{1}{m_2}
{{< /katex >}}

두 극단을 보면 뜻이 분명해집니다.

**질량이 같을 때** ({{< katex >}}m_1 = m_2 = m{{< /katex >}}):

{{< katex display=true >}}
\mu = \frac{m^2}{2m} = \frac{m}{2}
{{< /katex >}}

각 원자 질량의 절반입니다. 둘 다 움직이므로 하나만 움직일 때보다 "가볍게"
반응합니다.

**한쪽이 아주 무거울 때** ({{< katex >}}m_2 \gg m_1{{< /katex >}}):

{{< katex display=true >}}
\mu = \frac{m_1m_2}{m_1+m_2} \approx \frac{m_1m_2}{m_2} = m_1
{{< /katex >}}

가벼운 쪽의 질량으로 수렴합니다. 무거운 원자는 사실상 고정된 벽처럼 굴고
가벼운 원자만 떨린다는 뜻입니다. HCl 에서는 Cl 이 35 배 무거우므로 실제로 이
상황에 가깝습니다.

따라서 분자의 진동수는

{{< katex display=true >}}
\omega = \sqrt{\frac{k}{\mu}}
{{< /katex >}}

이고, {{< katex >}}k{{< /katex >}} 는 결합의 세기를,
{{< katex >}}\mu{{< /katex >}} 는 원자핵의 무게를 나릅니다.

## 동위원소 효과

이 식에서 곧바로 검증 가능한 예측이 나옵니다.

동위원소를 바꾸면 핵의 질량만 바뀌고 전자 구조는 거의 그대로입니다. 결합의
세기 {{< katex >}}k{{< /katex >}} 는 전자가 정하므로 변하지 않고, 변하는 것은
{{< katex >}}\mu{{< /katex >}} 뿐입니다.

{{< katex display=true >}}
\frac{\omega'}{\omega} = \sqrt{\frac{\mu}{\mu'}}
{{< /katex >}}

무거운 동위원소로 바꾸면 진동수가 내려갑니다. 화학적으로 거의 동일한 두
분자가 스펙트럼에서 뚜렷이 갈라져야 한다는 뜻이니 꽤 강한 예측이고, 아래
숫자에서 확인해 보겠습니다.

## 숫자로 확인하기

**HCl 의 진동수.** 힘 상수는
{{< katex >}}k \approx 481\ \mathrm{N/m}{{< /katex >}} 이고, 환산질량은

{{< katex display=true >}}
\mu = \frac{(1.008)(34.97)}{1.008 + 34.97} = 0.980\ \mathrm{amu}
= 1.627\times10^{-27}\ \mathrm{kg}
{{< /katex >}}

입니다. 예상대로 수소 질량 1.008 에 가깝고, 염소가 거의 움직이지 않는다는
뜻입니다.

{{< katex display=true >}}
\omega = \sqrt{\frac{481}{1.627\times10^{-27}}}
= \sqrt{2.96\times10^{29}} = 5.44\times10^{14}\ \mathrm{rad/s}
{{< /katex >}}

분광학에서 쓰는 파수로 바꾸면

{{< katex display=true >}}
\tilde{\nu} = \frac{\omega}{2\pi c}
= \frac{5.44\times10^{14}}{2\pi(2.998\times10^{10}\ \mathrm{cm/s})}
= 2.89\times10^{3}\ \mathrm{cm^{-1}}
{{< /katex >}}

실측값은 {{< katex >}}2886\ \mathrm{cm^{-1}}{{< /katex >}} 입니다. 포물선
하나로 세 자리가 맞는 셈입니다.

**영점에너지.**

{{< katex display=true >}}
E_0 = \tfrac{1}{2}\hbar\omega
= \tfrac{1}{2}(1.055\times10^{-34})(5.44\times10^{14})
= 2.87\times10^{-20}\ \mathrm{J} = 0.179\ \mathrm{eV}
{{< /katex >}}

진동은 상온에서 얼어 있습니다. 준위 간격은
{{< katex >}}\hbar\omega = 2E_0 = 0.358\ \mathrm{eV}{{< /katex >}} 인데, 상온
(300 K)의 열에너지는

{{< katex display=true >}}
kT = (1.381\times10^{-23})(300) = 4.14\times10^{-21}\ \mathrm{J} = 0.0257\ \mathrm{eV}
{{< /katex >}}

로 14 배 작습니다. Boltzmann 인자로 {{< katex >}}v=1{{< /katex >}} 에 있을
비율을 재 보면

{{< katex display=true >}}
\frac{N_1}{N_0} = e^{-\hbar\omega/kT} = e^{-13.9} \approx 9\times10^{-7}
{{< /katex >}}

백만 개 중 한 개꼴입니다. 그래서 적외선 흡수 스펙트럼에서 보이는 것은 거의
전부 {{< katex >}}v = 0 \to 1{{< /katex >}} 전이입니다.

이 계산은 [양자 가설]({{< ref "origins.md" >}})에서 본 Planck 의 논리와 정확히
같습니다. 에너지 덩어리가 {{< katex >}}kT{{< /katex >}} 보다 크면 그 자유도는
얼어붙습니다. 흑체의 고주파 mode 가 얼어붙어 자외선 파탄이 사라진 것과 HCl 의
진동이 상온에서 얼어 있는 것은 같은 현상입니다.

**동위원소 효과.** DCl 로 바꾸면 중수소가 두 배 무거우므로

{{< katex display=true >}}
\mu_{\mathrm{DCl}} = \frac{(2.014)(34.97)}{2.014+34.97} = 1.904\ \mathrm{amu}
{{< /katex >}}

{{< katex display=true >}}
\frac{\tilde{\nu}_{\mathrm{DCl}}}{\tilde{\nu}_{\mathrm{HCl}}}
= \sqrt{\frac{0.980}{1.904}} = 0.718
{{< /katex >}}

{{< katex display=true >}}
\tilde{\nu}_{\mathrm{DCl}} \approx 0.718 \times 2886 = 2.07\times10^{3}\ \mathrm{cm^{-1}}
{{< /katex >}}

실측은 약 {{< katex >}}2091\ \mathrm{cm^{-1}}{{< /katex >}} 입니다. 원자핵의
질량 하나만 바꿨는데 흡수선이 800 cm⁻¹ 나 이동했고, 그 이동폭이 예측과 1%
안에서 맞습니다. 진동이 정말로 질량에 의존하는 역학적 현상이라는 직접적인
증거입니다.

벽에 갇히는 경우와 용수철에 묶이는 경우를 보았습니다. 남은 한 가지는 묶이지도
갇히지도 않았는데 양자화되는 경우로,
[회전 운동과 각운동량]({{< ref "rotation.md" >}})에서 다루겠습니다.

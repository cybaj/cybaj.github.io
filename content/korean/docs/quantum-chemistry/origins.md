양자역학은 이론적 아름다움을 좇다가 나온 것이 아닙니다. 고전물리학이 명백히
틀린 답을 내놓는 실험이 몇 개 쌓였고, 그것을 맞추려는 임시방편에서 시작된
이론입니다. 그 임시방편이 결과적으로 물리학 전체를 다시 쓰게 만들었습니다.
(개인 노트: 1장 양자역학의 기원)

## 흑체 복사

### 무엇을 재는 실험인가

뜨거운 물체는 빛을 냅니다. 난로는 붉게, 더 뜨거운 것은 노랗게, 아주
뜨거우면 희게 보입니다.

그런데 물체마다 표면이 다르므로 색도 조금씩 다릅니다. 온도만의 효과를 보려면
표면의 개성을 지워야 하므로, 들어온 빛을 전부 흡수하는 이상적인 물체를
생각하고 이것을 **흑체**(blackbody)라 부릅니다.

실제로 만들 때는 속이 빈 공동에 작은 구멍을 뚫습니다. 구멍으로 들어간 빛은
안에서 벽에 부딪히기를 반복하다 결국 흡수되어 거의 나오지 못하므로, 구멍
자체가 완벽한 흡수체처럼 행동하게 됩니다. 이 공동을 데웠을 때 구멍에서 나오는
빛이 흑체 복사입니다.

### 무엇이 관측되는가

파장에 따라 세기를 재면 봉우리가 하나 있는 곡선이 나옵니다. 여기서 두 가지가
중요합니다.

첫째, 곡선이 온도에만 의존합니다. 공동을 무엇으로 만들었는지, 안쪽을 어떻게
칠했는지와는 무관합니다. 물질의 개성이 사라지고 온도 하나만 남는다는 것은, 이
곡선 뒤에 아주 일반적인 원리가 있다는 신호입니다.

둘째, 짧은 파장 쪽에서 세기가 0 으로 떨어집니다. 봉우리를 지나면 다시
내려가는 모양입니다.

온도를 올리면 봉우리가 짧은 파장 쪽으로 옮겨가는데, 난로가 붉다가 희어지는
이유가 여기에 있습니다.

설명해야 할 것은 이 곡선의 모양입니다.

## 고전물리학의 답과 그 실패

### 고전적 계산

공동 안의 전자기파를 정상파의 모음으로 봅니다. 양 끝이 고정된 줄처럼, 공동
안에는 정해진 파장의 정상파만 들어갈 수 있습니다.

파장이 짧을수록 공동 안에 더 많은 정상파가 들어가는데, 세어 보면 그 수가
진동수의 제곱에 비례합니다. 순수한 기하학이라 틀릴 여지가 없는 부분입니다.

여기에 고전 통계역학의 에너지 등분배 원리를 적용합니다. 열평형에서 각
자유도가 평균 {{< katex >}}kT{{< /katex >}} 만큼의 에너지를 갖는다는
원리입니다. 진동자 하나가 자유도 하나이므로 mode 하나마다
{{< katex >}}kT{{< /katex >}} 를 줍니다.

둘을 곱하면 Rayleigh–Jeans 법칙이 나옵니다.

{{< katex display=true >}}
\rho(\lambda,T)=\frac{8\pi kT}{\lambda^4}
{{< /katex >}}

### 자외선 파탄

긴 파장에서는 이 식이 실험과 잘 맞습니다. 문제는 반대쪽입니다.

{{< katex display=true >}}
\lambda \to 0 \quad \Longrightarrow \quad \rho(\lambda,T) \to \infty
{{< /katex >}}

흑체가 자외선에서 무한한 에너지를 방출해야 한다는 결론입니다. 방 안의 난로가
무한한 자외선을 쏟아내야 한다는 뜻이니 명백히 사실이 아니고, 실제로는 그
영역에서 세기가 0 으로 줄어듭니다.

이 어긋남을 **자외선 파탄**(ultraviolet catastrophe)이라 부릅니다.

### 어느 가정이 틀렸는가

무한대가 나왔다면 어딘가 틀린 것이므로, 어디가 틀렸는지 짚어 두는 것이
중요합니다.

가정은 두 개였습니다. 하나는 mode 수가 진동수의 제곱으로 는다는 것이고, 다른
하나는 각 mode 가 {{< katex >}}kT{{< /katex >}} 를 갖는다는 것입니다.

첫 번째는 기하학이라 틀릴 수 없으니, 두 번째가 틀린 셈입니다. 진동수가 아무리
높아도 각 mode 가 평균 {{< katex >}}kT{{< /katex >}} 를 갖는다는 가정이
문제였고, 고전 이론은 그 탓에 높은 진동수 mode 의 에너지를 과대평가하고
있었습니다.

## Planck 의 가설

### 가정

Planck 은 각 mode 를 조화진동자로 보되, 그 에너지가 연속적인 값을 가질 수
없다고 가정했습니다.

{{< katex display=true >}}
E_n = n h \nu \qquad (n = 0, 1, 2, \dots)
{{< /katex >}}

에너지를 아무 양이나 주고받을 수 없고 {{< katex >}}h\nu{{< /katex >}} 라는
덩어리 단위로만 오간다는 뜻입니다. {{< katex >}}h{{< /katex >}} 는 실험에
맞추기 위해 새로 도입한 상수입니다.

Planck 자신도 이것을 물리적 실재라기보다 수학적 편법으로 여겼다는 점은 덧붙여
둘 만합니다. 실제로 무엇을 뜻하는지는 한참 뒤에야 분명해졌습니다.

### 평균 에너지 유도

이 가정 하나가 어떻게 곡선을 고치는지 끝까지 따라가 보겠습니다.

열평형에서 에너지 {{< katex >}}E_n{{< /katex >}} 인 상태에 있을 확률은
Boltzmann 인자에 비례합니다.

{{< katex display=true >}}
P_n \propto e^{-E_n/kT} = e^{-n h\nu/kT}
{{< /katex >}}

표기를 줄이기 위해 {{< katex >}}\beta = 1/kT{{< /katex >}} 로 두면 분배함수는

{{< katex display=true >}}
Z = \sum_{n=0}^{\infty} e^{-\beta n h\nu}
= 1 + e^{-\beta h\nu} + e^{-2\beta h\nu} + \cdots
{{< /katex >}}

입니다. 공비가 {{< katex >}}e^{-\beta h\nu}{{< /katex >}} 인 등비급수이고,
이 값은 1 보다 작으므로 수렴합니다.

{{< katex display=true >}}
Z = \frac{1}{1 - e^{-\beta h\nu}}
{{< /katex >}}

여기가 고전 이론과 갈라지는 지점입니다. 에너지가 연속이었다면 이 자리에 합
대신 적분이 왔을 것이고, 그 적분은 {{< katex >}}kT{{< /katex >}} 를
내놓습니다. 합은 그렇지 않으니, 덩어리로 세느냐 연속으로 세느냐가 답을 바꾸는
셈입니다.

평균 에너지는 분배함수에서 바로 얻습니다.

{{< katex display=true >}}
\langle E \rangle
= \frac{\sum_n E_n e^{-\beta E_n}}{\sum_n e^{-\beta E_n}}
= -\frac{\partial}{\partial \beta} \ln Z
{{< /katex >}}

{{< katex >}}\ln Z = -\ln\big(1 - e^{-\beta h\nu}\big){{< /katex >}} 이므로
미분하면

{{< katex display=true >}}
\langle E \rangle
= \frac{h\nu\, e^{-\beta h\nu}}{1 - e^{-\beta h\nu}}
= \frac{h\nu}{e^{h\nu/kT} - 1}
{{< /katex >}}

마지막 등호는 분자와 분모에
{{< katex >}}e^{\beta h\nu}{{< /katex >}} 를 곱한 결과입니다.

### 이 식이 말하는 것

{{< katex >}}\langle E \rangle = h\nu/(e^{h\nu/kT}-1){{< /katex >}} 이 이
문서의 중심에 있는 식입니다. 두 극한을 보면 그 이유가 드러납니다.

**{{< katex >}}h\nu \ll kT{{< /katex >}} 일 때.** 지수를 전개하면
{{< katex >}}e^x \approx 1+x{{< /katex >}} 이므로
{{< katex >}}e^{h\nu/kT}-1 \approx h\nu/kT{{< /katex >}} 이고

{{< katex display=true >}}
\langle E \rangle \approx \frac{h\nu}{h\nu/kT} = kT
{{< /katex >}}

고전 결과로 돌아갑니다. 에너지 덩어리가 열에너지에 비해 아주 작으면 덩어리져
있다는 사실이 겉으로 드러나지 않습니다.

**{{< katex >}}h\nu \gg kT{{< /katex >}} 일 때.** 분모의 지수가 폭발적으로
커지므로

{{< katex display=true >}}
\langle E \rangle \to 0
{{< /katex >}}

높은 진동수 mode 는 얼어붙습니다. 이유를 말로 옮기면, 그 mode 는 에너지를
{{< katex >}}h\nu{{< /katex >}} 라는 덩어리로만 받을 수 있는데 주변의 열에너지
{{< katex >}}kT{{< /katex >}} 가 그 덩어리 하나 값에도 못 미치면 아예 여기될
수 없다는 것입니다. 잔돈이 부족해서 물건을 사지 못하는 것과 같습니다.

등분배가 무너지는 이유도, 자외선 파탄이 사라지는 이유도 여기에 있습니다.

### Planck 분포

mode 밀도에 이 평균 에너지를 곱하면

{{< katex display=true >}}
\rho(\nu,T) = \frac{8\pi h \nu^3}{c^3}\,\frac{1}{e^{h\nu/kT}-1}
{{< /katex >}}

이고 파장으로 바꾸면

{{< katex display=true >}}
\boxed{\;\rho(\lambda,T) = \frac{8\pi h c}{\lambda^5}\,\frac{1}{e^{hc/\lambda kT}-1}\;}
{{< /katex >}}

두 극한을 확인해 보겠습니다. 긴 파장에서는
{{< katex >}}hc/\lambda kT \ll 1{{< /katex >}} 이므로

{{< katex display=true >}}
\rho \approx \frac{8\pi hc}{\lambda^5}\cdot\frac{\lambda kT}{hc}
= \frac{8\pi kT}{\lambda^4}
{{< /katex >}}

정확히 Rayleigh–Jeans 법칙입니다. 짧은 파장에서는 지수가 폭발해
{{< katex >}}\rho \to 0{{< /katex >}} 이 됩니다.

하나의 식이 두 극한을 모두 맞춥니다. 고전 이론이 맞던 곳에서는 고전 이론으로
돌아가고 틀리던 곳에서는 실험을 맞히는데, 새 이론이 옛 이론을 대체할 때 갖춰야
할 모습입니다.

## 선스펙트럼: 원자도 띄엄띄엄하다

흑체는 뜨거운 물체 전체의 이야기였습니다. 개별 원자를 보면 더 분명한 증거가
있습니다.

기체를 방전시켜 나온 빛을 분광기에 통과시키면 연속된 띠가 아니라 정해진
파장의 선 몇 개만 나옵니다. 원소마다 선의 위치가 다르고, 같은 원소는 언제나
같은 선을 냅니다.

원자가 아무 에너지나 가질 수 있다면 이럴 수 없습니다. 연속적인 에너지 차이가
가능하다면 연속적인 파장이 나와야 하기 때문입니다.

원자가 {{< katex >}}E_2{{< /katex >}} 에서
{{< katex >}}E_1{{< /katex >}} 로 떨어지며 광자 하나를 내놓는다고 보면

{{< katex display=true >}}
\boxed{\;\Delta E = E_2 - E_1 = h\nu\;}
{{< /katex >}}

선스펙트럼이 존재한다는 것은 원자의 에너지 준위가 띄엄띄엄하다는 말과
같습니다. 관측되는 것은 빛이지만, 그것이 알려 주는 것은 원자 내부의
구조입니다.

## Franck–Hertz: 준위를 직접 때려 보기

선스펙트럼은 간접 증거입니다. 원자가 내놓은 빛을 보고 준위를 추론한 것이기
때문입니다. 준위가 정말 띄엄띄엄한지 직접 확인한 실험도 있습니다.

전자를 전압 {{< katex >}}V{{< /katex >}} 로 가속하면 운동에너지
{{< katex >}}E_k = eV{{< /katex >}} 를 얻습니다. 이 전자를 수은 증기에 쏘아
원자와 충돌시킵니다.

**원자가 에너지를 연속적으로 받을 수 있다면** 전자는 충돌할 때마다 조금씩
에너지를 잃어야 하고, 전압을 올리면 전류가 매끄럽게 변해야 합니다.

실제로는 그렇지 않습니다. 전압이 어떤 값에 이를 때까지 전자는 원자와 거의
탄성 충돌만 하는데, 에너지를 주지 못하고 튕겨 나온다는 뜻입니다. 그러다 전압이
특정 값을 넘는 순간 전자가 갑자기 에너지를 잃으면서 전류가 뚝 떨어지고, 전압을
더 올리면 같은 간격으로 이 일이 반복됩니다.

{{< katex display=true >}}
eV_{\text{exc}} = \Delta E
{{< /katex >}}

원자는 정해진 양의 에너지만 받습니다. 그보다 적으면 아예 받지 않고, 그만큼이
되어야 받습니다. 빛을 거치지 않고 전자 충돌만으로 확인했다는 점에서
선스펙트럼보다 직접적인 증거입니다.

## 광전효과

### 세 가지 관측

금속에 빛을 쬐면 전자가 튀어나옵니다. 실험이 보여 준 것은 셋입니다.

1. 빛의 진동수가 금속마다 정해진 문턱값보다 작으면, 아무리 세게 비춰도
   전자가 나오지 않습니다.
2. 나온 전자의 운동에너지는 빛의 세기가 아니라 진동수에 선형으로 비례합니다.
3. 진동수가 문턱을 넘으면, 빛이 아무리 약해도 전자가 즉시 나옵니다.

### 고전적으로 왜 말이 안 되는가

빛이 파동이라면 에너지는 세기가 나릅니다. 그렇다면

- 약한 빛이라도 오래 쬐면 전자가 에너지를 조금씩 모아 결국 튀어나와야
  합니다. 그런데 3 번은 기다림이 없다고 말합니다.
- 센 빛이면 진동수가 낮아도 전자가 나와야 합니다. 그런데 1 번은 진동수가
  낮으면 아무리 세도 나오지 않는다고 말합니다.
- 운동에너지는 세기에 의존해야 합니다. 그런데 2 번은 진동수가 정한다고
  말합니다.

세 가지가 모두 어긋나므로, 단순한 수정으로 될 일이 아닙니다.

### Einstein 의 설명

Einstein 은 빛이 {{< katex >}}h\nu{{< /katex >}} 의 에너지를 가진 알갱이,
**광자**(photon)로도 작용한다고 보았습니다. 그리고 전자 하나가 광자 하나를
통째로 흡수한다고 놓았습니다.

금속에서 전자를 떼어내는 데 드는 최소 에너지를
**일함수**(work function) {{< katex >}}\Phi{{< /katex >}} 라 하면, 광자
에너지는 두 몫으로 쓰입니다.

{{< katex display=true >}}
h\nu = \Phi + E_k
\qquad \Longrightarrow \qquad
\boxed{\;E_k = h\nu - \Phi\;}
{{< /katex >}}

세 관측이 한꺼번에 설명됩니다.

운동에너지가 0 이 되는 자리가 문턱이므로

{{< katex display=true >}}
\nu_0 = \frac{\Phi}{h}
{{< /katex >}}

이고, {{< katex >}}\nu < \nu_0{{< /katex >}} 이면 광자 하나의 에너지가
애초에 모자랍니다. 세기를 올리는 것은 광자의 수를 늘리는 일이지 광자 하나의
에너지를 올리는 일이 아니므로 소용이 없습니다. 그리고 흡수는 광자 하나와 전자
하나 사이의 일회성 거래이므로 기다릴 이유도 없습니다.

## de Broglie 관계식

광전효과는 파동인 줄 알았던 빛이 입자처럼 군다는 것을 보여 주었습니다.
de Broglie 는 여기서 자연스러운 반대 질문을 던졌습니다. 입자인 줄 알았던
전자도 파동처럼 굴지 않겠느냐는 것입니다.

광자에 대해 {{< katex >}}E = h\nu{{< /katex >}} 와 상대론의
{{< katex >}}E = pc{{< /katex >}}, 그리고
{{< katex >}}\nu\lambda = c{{< /katex >}} 를 함께 쓰면

{{< katex display=true >}}
pc = h\nu = \frac{hc}{\lambda}
\qquad \Longrightarrow \qquad
p = \frac{h}{\lambda}
{{< /katex >}}

de Broglie 는 이 관계가 빛뿐 아니라 모든 물질에 성립한다고 제안했습니다.

{{< katex display=true >}}
\boxed{\;\lambda = \frac{h}{p} = \frac{h}{mv}\;}
{{< /katex >}}

근거는 대칭성이었습니다. 빛이 파동이면서 입자라면 물질도 그래야 한다는
것입니다. 당시로서는 대담한 추측이었지만 곧 전자 회절로 확인되었습니다.
결정에 전자빔을 쏘면 X선과 똑같은 회절 무늬가 나옵니다.

## 불확정성 원리

입자가 파동이라면 "이 순간 여기 있고 이만큼의 속도로 움직인다" 는 말이
성립하지 않습니다. 파동의 성질을 생각해 보면 이유가 보입니다.

파장이 정확히 정해진 파동은 공간 전체에 퍼져 있습니다.
{{< katex >}}\sin kx{{< /katex >}} 는 어디서 시작하지도 끝나지도 않으니,
파장이 확실하면 위치가 없는 셈입니다.

**위치가 한 점에 몰린 파동을 만들려면** 여러 파장의 파동을 겹쳐야 합니다.
그러면 파장이 하나로 정해지지 않고, de Broglie 관계에 의해 운동량도 하나로
정해지지 않습니다.

{{< katex display=true >}}
\boxed{\;\Delta x \, \Delta p \ge \frac{\hbar}{2}\;}
{{< /katex >}}

이것은 측정 기술의 한계가 아닙니다. 더 좋은 장치를 만들면 해결되는 문제가
아니라, 파동으로 기술되는 대상이 원래 갖는 성질입니다.

그래서 전자가 핵 주위를 도는 궤도라는 그림이 무너집니다. 궤도는 매 순간의
위치와 속도를 동시에 지정하는 개념인데, 그런 것이 애초에 존재하지 않기
때문입니다.

## 숫자로 확인하기

**나트륨의 590 nm 방출선.** 이 선에 대응하는 원자 내부의 에너지 차이는

{{< katex display=true >}}
\Delta E = \frac{hc}{\lambda}
= \frac{(6.626\times10^{-34})(2.998\times10^{8})}{590\times10^{-9}}
= 3.37\times10^{-19}\ \mathrm{J}
{{< /katex >}}

{{< katex >}}1\ \mathrm{eV} = 1.602\times10^{-19}\ \mathrm{J}{{< /katex >}} 로
나누면 2.10 eV 입니다. 화학결합 에너지가 대략 이 자릿수(몇 eV)라는 점이
중요합니다. 분광학이 화학의 도구인 이유가 여기에 있는데, 원자와 분자의 에너지
변화가 마침 가시광선 광자의 에너지와 같은 크기이기 때문입니다.

**Franck–Hertz 와 수은.** 수은의 들뜸 전압은 4.9 V 로 관측됩니다. 따라서

{{< katex display=true >}}
\Delta E = eV = 4.9\ \mathrm{eV}
{{< /katex >}}

만약 이 준위가 실재한다면, 들뜬 수은 원자가 바닥으로 떨어지며 이 에너지에
해당하는 빛을 내놓아야 합니다.

{{< katex display=true >}}
\lambda = \frac{hc}{\Delta E} = \frac{1240\ \mathrm{eV\cdot nm}}{4.9\ \mathrm{eV}}
= 253\ \mathrm{nm}
{{< /katex >}}

수은 램프의 대표적인 자외선 방출선이 253.7 nm 입니다. 전자를 때려서 잰 값과
빛을 보고 잰 값이 일치하는 것입니다. 전혀 다른 두 실험이 같은 준위를
가리킨다는 것은 그 준위가 실재한다는 든든한 증거입니다.

**100 V 로 가속한 전자의 파장.**
{{< katex >}}E_k = 100\ \mathrm{eV} = 1.602\times10^{-17}\ \mathrm{J}{{< /katex >}}
이므로

{{< katex display=true >}}
p = \sqrt{2mE_k} = \sqrt{2(9.109\times10^{-31})(1.602\times10^{-17})}
= 5.40\times10^{-24}\ \mathrm{kg\,m/s}
{{< /katex >}}

{{< katex display=true >}}
\lambda = \frac{h}{p} = \frac{6.626\times10^{-34}}{5.40\times10^{-24}}
= 1.23\times10^{-10}\ \mathrm{m} = 123\ \mathrm{pm}
{{< /katex >}}

원자 사이의 간격과 같은 크기입니다. 그래서 전자빔이 결정에서 회절합니다.
결정의 원자 배열이 마침 이 파장에 맞는 회절격자 노릇을 하는 것입니다.

**야구공은 왜 회절하지 않는가.**
{{< katex >}}m = 0.145\ \mathrm{kg}{{< /katex >}},
{{< katex >}}v = 40\ \mathrm{m/s}{{< /katex >}} 이면

{{< katex display=true >}}
\lambda = \frac{6.626\times10^{-34}}{(0.145)(40)} = 1.1\times10^{-34}\ \mathrm{m}
{{< /katex >}}

양성자 지름의 {{< katex >}}10^{-19}{{< /katex >}} 배입니다. 물질파는
야구공에도 있지만 어떤 방법으로도 잴 수 없습니다. 양자역학이 일상에서 보이지
않는 이유는 법칙이 달라서가 아니라 {{< katex >}}h{{< /katex >}} 가 작기
때문입니다.

**전자를 원자 크기에 가두면.**
{{< katex >}}\Delta x \approx 100\ \mathrm{pm}{{< /katex >}} 로 두면

{{< katex display=true >}}
\Delta p \ge \frac{\hbar}{2\Delta x}
= \frac{1.055\times10^{-34}}{2(1.0\times10^{-10})}
= 5.3\times10^{-25}\ \mathrm{kg\,m/s}
{{< /katex >}}

{{< katex display=true >}}
\Delta v \ge \frac{5.3\times10^{-25}}{9.109\times10^{-31}}
\approx 5.8\times10^{5}\ \mathrm{m/s}
{{< /katex >}}

속도의 불확정성이 초당 580 km 입니다. 그런데
[수소 원자]({{< ref "hydrogen.md" >}})에서 전자의 실제 속도는
{{< katex >}}2.2\times10^6\ \mathrm{m/s}{{< /katex >}} 정도이니, 불확정성이
속도 자체의 4분의 1 이나 되는 셈입니다. 이 정도면 "전자의 속도"를 하나의 값으로
말하는 것이 무의미하고, 궤도라는 그림을 왜 버려야 하는지가 숫자로 드러납니다.

실험이 요구하는 것은 이제 분명합니다. 에너지가 띄엄띄엄하다는 것과 물질이
파동이라는 것을 함께 담는 기술이 필요하고, 그 기술을
[파동함수와 Schrödinger 방정식]({{< ref "wavefunction.md" >}})에서
세우겠습니다.

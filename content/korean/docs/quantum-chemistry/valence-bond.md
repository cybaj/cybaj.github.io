[Born–Oppenheimer 근사]({{< ref "born-oppenheimer.md" >}})가 문제를 둘로
쪼개 주었으니, 이제 전자 쪽 문제를 실제로 풀 차례입니다. 두 가지 전통이
있는데, 여기서는 그중 화학자의 직관에 가까운 쪽을 다룹니다.
(개인 노트: 10장 Valence-Bond 이론)

## 출발점: 결합은 겹침이다

Valence-Bond 이론의 관점은 한 문장으로 요약됩니다.

> 화학 결합은 서로 다른 원자의 원자 오비탈이 겹치고, 그 오비탈에 있는 두
> 전자가 반대 스핀으로 짝지을 때 만들어집니다.

Lewis 가 그은 결합선 하나가 전자쌍 하나에 대응한다는 그림을 그대로
양자역학으로 번역한 것입니다. 원자는 결합 후에도 자기 정체성을 상당히 유지하고,
결합은 두 원자 사이에 국소화되어 있다고 봅니다.

이 관점이 얼마나 자연스러운지는 반대쪽을 생각해 보면 드러납니다.
[분자 오비탈 이론]({{< ref "molecular-orbital.md" >}})은 전자가 처음부터 분자
전체에 속한다고 보므로, 그 관점에서는 "C–H 결합" 같은 것이 따로 존재하지
않습니다. 화학자가 일상적으로 쓰는 언어에 더 가까운 쪽은 분명히 VB
입니다.

## 수소 분자를 직접 써 보기

원자 A 와 B 가 각각 전자 하나씩을 가지고 있다고 하겠습니다. 전자에 1, 2 라는
이름을 붙이고 가장 단순하게 써 보면

{{< katex display=true >}}
\psi = A(1)B(2)
{{< /katex >}}

"전자 1 은 A 에, 전자 2 는 B 에 있다"는 뜻입니다.

그런데 이 식은 맞지 않습니다. 전자는 구별할 수 없기 때문입니다. 1 번과
2 번이라고 이름을 붙였을 뿐, 실제로 어느 전자가 어느 원자에 있는지는 말할 수
없습니다. {{< katex >}}A(2)B(1){{< /katex >}} 도 똑같이 가능한 배치입니다.

두 가능성을 모두 담으려면 섞어야 하고, 부호는 두 가지가 가능합니다.

{{< katex display=true >}}
\boxed{\;\psi_\pm = \frac{A(1)B(2) \pm A(2)B(1)}{\left[2(1 \pm S^2)\right]^{1/2}}\;}
{{< /katex >}}

분모는 정규화 상수이고 {{< katex >}}S{{< /katex >}} 는 겹침 적분입니다.

{{< katex display=true >}}
S = \int A^*B\,d\tau
{{< /katex >}}

두 오비탈이 공간적으로 얼마나 포개지는지를 재는 양입니다. 멀리 떨어져 있으면
0 이고 가까울수록 커집니다.

## 부호 하나가 결합을 만든다

두 부호가 전혀 다른 결과를 줍니다. 확률밀도를 보면 알 수 있습니다.

{{< katex display=true >}}
|\psi_\pm|^2 \propto \left[A(1)B(2)\right]^2 + \left[A(2)B(1)\right]^2
\pm 2\,A(1)B(2)A(2)B(1)
{{< /katex >}}

앞의 두 항은 부호와 무관하므로 차이는 교차항에서 옵니다. 이 항은 두 오비탈이
겹치는 영역, 즉 두 핵 사이에서 큽니다.

{{< katex display=true >}}
\psi_+ \Rightarrow \text{핵 사이 전자밀도 증가} \Rightarrow \text{에너지 감소}
\Rightarrow \text{결합}
{{< /katex >}}
{{< katex display=true >}}
\psi_- \Rightarrow \text{핵 사이 전자밀도 감소} \Rightarrow \text{에너지 증가}
\Rightarrow \text{반결합}
{{< /katex >}}

결합이란 전자밀도가 두 핵 사이에 쌓이는 일입니다. 그 자리에 있는 전자는 양쪽
핵에 동시에 끌리므로 에너지가 내려가고, 한쪽 핵에만 붙어 있는 전자보다
유리해집니다.

[Born–Oppenheimer]({{< ref "born-oppenheimer.md" >}})에서 본
{{< katex >}}\mathrm{H}_2^+{{< /katex >}} 의 두 곡선, 즉 최소점이 있는 것과
없는 것의 정체가 바로 이것입니다.

## 스핀은 선택이 아니라 강제다

여기서 중요한 일이 벌어집니다. 스핀 이야기를 아직 꺼내지도 않았는데
Pauli 원리가 스핀을 강제합니다.

[다전자 원자]({{< ref "many-electron.md" >}})에서 본 대로 전체 파동함수는
반대칭이어야 합니다.

{{< katex display=true >}}
\Psi(1,2) = -\Psi(2,1)
{{< /katex >}}

전체 파동함수는 공간 부분과 스핀 부분의 곱입니다.

{{< katex display=true >}}
\Psi(1,2) = \psi(1,2)\,\sigma(1,2)
{{< /katex >}}

그런데 결합을 만드는 {{< katex >}}\psi_+{{< /katex >}} 는 1 과 2 를 맞바꿔도
그대로인 대칭 함수입니다. 곱이 반대칭이 되려면 스핀 부분이 반대칭이어야 하고,
그런 스핀 함수는 하나뿐입니다.

{{< katex display=true >}}
\sigma_-(1,2) = \frac{1}{\sqrt{2}}\left[\alpha(1)\beta(2) - \alpha(2)\beta(1)\right]
{{< /katex >}}

단일항, 즉 스핀이 반대로 짝지은 상태입니다. 따라서 결합 상태는

{{< katex display=true >}}
\boxed{\;\Psi_{\text{bond}} = \psi_+(1,2)\,\sigma_-(1,2)\;}
{{< /katex >}}

입니다.

전자쌍이 왜 반대 스핀이어야 하는지가 여기서 유도되었습니다. 결합은 전자 둘이
짝을 이룬다는, 화학이 오래 경험적으로 알고 있던 사실이 대칭성의 결과로 나온
것입니다. Lewis 의 결합선 하나가 정확히 이 상태에 대응합니다.

## 에너지는 어떻게 생겼는가

변분법으로 에너지를 구하면

{{< katex display=true >}}
E_\pm = \frac{H_{11} \pm H_{12}}{1 \pm S^2}
{{< /katex >}}

꼴이 됩니다. {{< katex >}}H_{11}{{< /katex >}} 은 전자가 각자 자기 원자에
있을 때의 에너지에 해당하고, {{< katex >}}H_{12}{{< /katex >}} 는 두 배치가
섞이면서 생기는 항입니다.

{{< katex >}}H_{12}{{< /katex >}} 를 **교환 적분**(exchange integral)이라
부르며, 결합 에너지의 대부분이 여기서 나옵니다. 고전적으로는 대응하는 것이 없는
항으로, 두 전자를 맞바꾼 배치가 섞일 수 있다는 순수한 양자역학적 사실에서
생깁니다.

화학 결합의 상당 부분은 고전적으로 설명할 수 없다는 뜻입니다. 정전기적
인력만으로는 결합이 왜 그렇게 강한지 설명되지 않습니다.

## σ 결합과 π 결합

오비탈이 겹치는 방식에 따라 결합의 종류가 갈립니다.

**σ 결합**은 결합축을 중심으로 원통 대칭입니다. 축 방향에서 정면으로 겹칠 때
생깁니다. {{< katex >}}s{{< /katex >}}–{{< katex >}}s{{< /katex >}},
{{< katex >}}s{{< /katex >}}–{{< katex >}}p_z{{< /katex >}},
{{< katex >}}p_z{{< /katex >}}–{{< katex >}}p_z{{< /katex >}} 가
그렇습니다. 축을 중심으로 돌려도 모양이 변하지 않습니다.

**π 결합**은 결합축을 포함하는 마디면을 갖습니다. 축에 수직인
{{< katex >}}p{{< /katex >}} 오비탈끼리 옆으로 겹칠 때 생기며, 축 위에서는
전자밀도가 0 입니다.

겹침의 크기가 다르므로 세기도 다릅니다. 정면으로 겹치는 σ 가 옆으로 스치는 π
보다 겹침이 크고, 따라서 더 강합니다. 이중결합이 단일결합의 두 배로 강하지 않은
이유가 여기에 있습니다. 이중결합은 σ 하나에 π 하나이고, π 가 σ 보다 약하기
때문입니다.

{{< katex display=true >}}
\text{단일결합} = \sigma, \qquad
\text{이중결합} = \sigma + \pi, \qquad
\text{삼중결합} = \sigma + 2\pi
{{< /katex >}}

그리고 π 결합은 옆으로 겹치는 방식이라 비틀면 끊어집니다. σ 결합 축을
중심으로 회전하면 π 의 겹침이 사라지기 때문입니다. 알켄이 회전하지 못해
시스–트랜스 이성질체를 갖는 이유이자, 알케인이 자유롭게 회전하는
이유입니다.

## 공명

VB 이론에는 구조 하나로 표현되지 않는 분자들이 있습니다. 벤젠이
대표적입니다.

Kekulé 구조를 두 개 그릴 수 있는데, 실제 벤젠은 그중 어느 하나도 아닙니다.
결합 길이가 모두 같고, 에너지도 어느 한 구조보다 낮습니다.

VB 는 이것을 여러 구조의 중첩으로 다룹니다.

{{< katex display=true >}}
\psi = c_1\psi_1 + c_2\psi_2 + \cdots
{{< /katex >}}

이 중첩이 어느 개별 구조보다 낮은 에너지를 주며, 그 차이를 공명 안정화
에너지라 합니다.

흔한 오해를 하나 짚어 두겠습니다. 공명은 분자가 두 구조 사이를 왔다 갔다
한다는 뜻이 아닙니다. 분자는 언제나 하나의 상태에 있고, 그 상태를 그릴 수 있는
구조들의 합으로 표현할 뿐입니다. 왔다 갔다 하는 것은 분자가 아니라
표기법입니다.

## Promotion 과 혼성화

VB 가 실제 분자 구조를 설명하려면 장치가 하나 더 필요합니다. 메테인을 예로
들겠습니다.

탄소의 바닥 상태 전자배치는
{{< katex >}}1s^22s^22p^2{{< /katex >}} 입니다. 홀전자가 둘뿐이므로 결합도
둘밖에 만들지 못해야 하는데, 메테인은 C–H 결합이 넷입니다.

먼저 {{< katex >}}2s{{< /katex >}} 전자 하나를 빈
{{< katex >}}2p{{< /katex >}} 로 올립니다(promotion).

{{< katex display=true >}}
2s^22p^2 \longrightarrow 2s^12p^3
{{< /katex >}}

이제 홀전자가 넷이라 결합을 넷 만들 수 있습니다. 승격에 에너지가 들지만
결합을 둘 더 만들어 얻는 이득이 훨씬 큽니다.

그런데 이대로는 문제가 남습니다. {{< katex >}}2s{{< /katex >}} 하나와
{{< katex >}}2p{{< /katex >}} 셋은 모양도 방향도 다르므로 C–H 결합 넷이 서로
달라야 하는데, 실제 메테인의 네 결합은 완전히 똑같고 결합각이 109.5°
입니다.

그래서 섞습니다. 이것이 **혼성화**(hybridization)입니다.

{{< katex display=true >}}
sp^3: \quad 2s + 2p_x + 2p_y + 2p_z \longrightarrow 4\text{개의 등가 오비탈}
{{< /katex >}}

넷이 정사면체의 꼭짓점 방향을 향하고, 서로 이루는 각이 정확히 109.47°
입니다.

혼성화는 물리적 과정이 아니라 수학적 재조합입니다. 탄소 원자가 "먼저
혼성화한 다음 결합한다"는 뜻이 아닙니다. 같은 네 개의 함수를 다른 기저로 다시
쓴 것일 뿐이고, 그 기저가 분자의 대칭에 맞아떨어져 결합을 기술하기 편할
뿐입니다.

섞는 비율을 바꾸면 다른 기하가 나옵니다.

| 혼성 | 섞는 것 | 방향 | 결합각 | 예 |
|---|---|---|---|---|
| {{< katex >}}sp^3{{< /katex >}} | {{< katex >}}s + 3p{{< /katex >}} | 정사면체 | 109.5° | {{< katex >}}\mathrm{CH_4}{{< /katex >}} |
| {{< katex >}}sp^2{{< /katex >}} | {{< katex >}}s + 2p{{< /katex >}} | 평면 삼각 | 120° | {{< katex >}}\mathrm{C_2H_4}{{< /katex >}} |
| {{< katex >}}sp{{< /katex >}} | {{< katex >}}s + p{{< /katex >}} | 직선 | 180° | {{< katex >}}\mathrm{C_2H_2}{{< /katex >}} |

에틴({{< katex >}}\mathrm{C_2H_4}{{< /katex >}})에서는
{{< katex >}}sp^2{{< /katex >}} 셋이 평면에 놓여 σ 결합을 만들고, 남은
{{< katex >}}p{{< /katex >}} 오비탈이 평면 위아래로 π 결합을 만듭니다.
그래서 에틴은 평평하고 C=C 축을 중심으로 회전하지 못합니다.
에타인({{< katex >}}\mathrm{C_2H_2}{{< /katex >}})에서는
{{< katex >}}sp{{< /katex >}} 둘이 직선을 만들고 남은
{{< katex >}}p{{< /katex >}} 둘이 π 결합 둘을 만들어 삼중결합이 됩니다.

## 숫자로 확인하기

**{{< katex >}}\mathrm{H}_2{{< /katex >}} 를 가장 단순한 VB 로 계산하면.**
위에서 쓴 {{< katex >}}\psi_+{{< /katex >}} 하나만으로 계산하면

{{< katex display=true >}}
R_e \approx 87\ \mathrm{pm}, \qquad D_e \approx 303\ \mathrm{kJ/mol}
{{< /katex >}}

가 나옵니다. 실측은

{{< katex display=true >}}
R_e = 74\ \mathrm{pm}, \qquad D_e = 458\ \mathrm{kJ/mol}
{{< /katex >}}

입니다. 결합 길이는 18% 길고 결합 에너지는 34% 모자랍니다.

그래도 방향은 맞습니다. 최소점이 있는 곡선이 나왔고, 결합이 존재한다는 사실도
크기의 자릿수도 실측과 어긋나지 않습니다. 원자 오비탈 두 개를 겹친 가장 거친
근사가 이미 화학 결합을 설명한다는 점이 중요합니다.

부족한 부분은 개선할 수 있습니다. 이온
구조({{< katex >}}\mathrm{H^-H^+}{{< /katex >}} 와
{{< katex >}}\mathrm{H^+H^-}{{< /katex >}})를 섞고 오비탈을 수축시키면
{{< katex >}}D_e{{< /katex >}} 가 400 kJ/mol 을 넘습니다. VB 는 틀린 이론이
아니라 거친 이론이며, 개선의 방향이 분명한 이론입니다.

**결합각이 정말 109.47° 인가.** 정사면체의 중심에서 두 꼭짓점을 향하는 벡터
사이의 각을 구해 보겠습니다. 정육면체의 서로 마주 보는 꼭짓점을 골라
{{< katex >}}(1,1,1){{< /katex >}} 과
{{< katex >}}(1,-1,-1){{< /katex >}} 로 두면

{{< katex display=true >}}
\cos\theta = \frac{(1)(1) + (1)(-1) + (1)(-1)}{\sqrt{3}\sqrt{3}} = -\frac{1}{3}
{{< /katex >}}

{{< katex display=true >}}
\theta = \arccos\left(-\tfrac{1}{3}\right) = 109.47^\circ
{{< /katex >}}

메테인의 실측 결합각이 109.5° 입니다. 순수한 기하학에서 나온 숫자가 분자에서
그대로 관측되는 것입니다.

다만 이것은 네 결합이 모두 같을 때의 값입니다. 암모니아는 107°, 물은 104.5° 로
조금씩 작습니다. 고립 전자쌍이 결합쌍보다 더 넓은 공간을 차지해 결합각을
밀어내기 때문이고, {{< katex >}}sp^3{{< /katex >}} 라는 이상적인 그림에서
벗어나는 정도가 고립 전자쌍의 수와 정확히 대응합니다.

VB 는 결합선, 혼성, 공명이라는 화학자의 언어를 그대로 줍니다. 그런데 설명하지
못하는 것이 하나 있습니다. 액체 산소가 자석에 붙는다는 사실이고, 그 이야기를
[분자 오비탈 이론]({{< ref "molecular-orbital.md" >}})에서 하겠습니다.

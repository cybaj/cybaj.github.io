[수소꼴 원자]({{< ref "hydrogen.md" >}})는 정확히 풀렸습니다. 그런데
주기율표에는 원소가 118 개 있고 그중 수소꼴은 사실상 하나뿐입니다. 전자가 둘만
되어도 상황이 달라지는데, 화학은 바로 거기서부터 시작됩니다.
(개인 노트: 7장 다전자 원자)

## 전자 하나가 늘면 무엇이 달라지는가

헬륨을 생각해 보겠습니다. 핵전하 {{< katex >}}+2e{{< /katex >}} 에 전자
둘입니다. Hamiltonian 을 써 보면

{{< katex display=true >}}
\hat{H} = \underbrace{-\frac{\hbar^2}{2m}\nabla_1^2 - \frac{2e^2}{4\pi\varepsilon_0 r_1}}_{\text{전자 1}}
\;\underbrace{-\frac{\hbar^2}{2m}\nabla_2^2 - \frac{2e^2}{4\pi\varepsilon_0 r_2}}_{\text{전자 2}}
\;+\;\underbrace{\frac{e^2}{4\pi\varepsilon_0 r_{12}}}_{\text{반발}}
{{< /katex >}}

앞의 두 묶음은 각각 수소꼴 원자와 똑같으므로 문제될 것이 없습니다. 문제는
마지막 항입니다.

{{< katex display=true >}}
\frac{e^2}{4\pi\varepsilon_0 r_{12}},
\qquad r_{12} = |\mathbf{r}_1 - \mathbf{r}_2|
{{< /katex >}}

두 전자 사이의 반발이고, 두 전자의 좌표가 섞여 있습니다. 이 항 때문에
변수분리가 불가능해집니다. 전자 1 의 방정식을 풀려면 전자 2 가 어디 있는지
알아야 하고, 전자 2 를 풀려면 전자 1 을 알아야 하기 때문입니다.

세 물체가 서로 끌고 밀면 정확한 해가 없습니다. 고전역학의 삼체 문제와 같은
사정입니다. 헬륨 원자는 우주에서 두 번째로 단순한 원자인데도 해석적으로 풀리지
않습니다.

그러니 근사해야 합니다. 아래에 나오는 개념들은 모두 그 근사를 정당화하거나
보정하는 장치입니다.

## 오비탈 근사

가장 기본이 되는 근사는, 각 전자가 다른 전자들이 만드는 평균적인 전하 구름
속을 홀로 움직인다고 보는 것입니다.

그러면 전체 파동함수를 한 전자 함수들의 곱으로 쓸 수 있습니다.

{{< katex display=true >}}
\boxed{\;\Psi(\mathbf{r}_1,\mathbf{r}_2,\dots) \approx
\psi_a(\mathbf{r}_1)\,\psi_b(\mathbf{r}_2)\cdots\;}
{{< /katex >}}

각 {{< katex >}}\psi{{< /katex >}} 를 오비탈이라 부릅니다. 이렇게 하면 다시
한 전자 문제가 되고, 수소에서 배운 것을 그대로 쓸 수 있습니다.

무엇을 버렸는지 분명히 해 두는 것이 중요합니다. 실제 전자들은 순간순간 서로를
피해서, 하나가 왼쪽에 있으면 다른 하나는 오른쪽에 있을 가능성이 큽니다. 평균
전하 구름으로 바꾸면 이 상관관계가 사라집니다. 그래서 오비탈 근사는 언제나
반발을 조금 과대평가하고, 계산된 에너지는 실제보다 높게 나옵니다. 이 차이를
**전자 상관**(electron correlation)이라 하며, 현대 계산화학의 상당 부분이
이것을 되찾는 일에 쓰입니다.

그래도 이 근사를 쓰는 이유는 분명합니다. 화학의 언어가 모두 여기서 나오기
때문입니다. 1s, 2p, 전자배치, 궤도함수 같은 개념은 오비탈 근사 안에서만 뜻이
있습니다. 엄밀히 말하면 다전자 원자에 "2p 오비탈에 있는 전자" 같은 것은
없습니다. 그런데도 그렇게 말하는 것은 그 언어가 놀랄 만큼 잘 작동하기
때문입니다.

## 스핀과 Pauli 원리

전자에는 위치와 무관한 성질이 하나 더 있습니다. 스핀입니다.

Stern–Gerlach 실험이 그것을 보여 주었습니다. 은 원자 빔을 불균일한 자기장에
통과시키면 빔이 정확히 둘로 갈라집니다. 고전적으로는 자기 모멘트의 방향이
연속적이므로 연속적인 띠가 나와야 하니, 둘로 갈라진다는 것은 자기 모멘트의
{{< katex >}}z{{< /katex >}} 성분이 두 값만 갖는다는 뜻입니다.

이것은 궤도 각운동량으로 설명되지 않습니다. 궤도 각운동량은
{{< katex >}}2l+1{{< /katex >}} 개, 즉 홀수 개로 갈라지기 때문입니다. 둘로
갈라지려면 {{< katex >}}2s+1 = 2{{< /katex >}}, 즉

{{< katex display=true >}}
s = \tfrac{1}{2}
{{< /katex >}}

이어야 합니다. 반정수 각운동량이고 궤도 운동으로는 만들 수 없으니, 전자가
본래 가지고 있는 성질입니다.

{{< katex display=true >}}
|\mathbf{s}| = \sqrt{s(s+1)}\,\hbar = \frac{\sqrt{3}}{2}\hbar,
\qquad m_s = +\tfrac{1}{2}\ \text{또는}\ -\tfrac{1}{2}
{{< /katex >}}

흔히 {{< katex >}}\alpha{{< /katex >}}(위)와
{{< katex >}}\beta{{< /katex >}}(아래)로 적습니다.

### 파동함수는 반대칭이어야 한다

이제 결정적인 원리가 나옵니다. 전자는 서로 구별할 수 없습니다. 두 전자에
이름을 붙여 1 번 2 번이라 불렀지만, 그 이름을 맞바꿔도 물리적으로 같은
상태여야 합니다.

{{< katex display=true >}}
|\Psi(1,2)|^2 = |\Psi(2,1)|^2
{{< /katex >}}

제곱이 같으려면 파동함수 자체에는 부호까지 포함해 두 가지 가능성이 있습니다.
자연은 입자 종류에 따라 둘 중 하나를 고르는데, 전자를 포함한 페르미온은 음의
부호를 택합니다.

{{< katex display=true >}}
\boxed{\;\Psi(1,2) = -\Psi(2,1)\;}
{{< /katex >}}

이것이 Pauli 원리의 본래 형태입니다. 흔히 배우는 "한 오비탈에 전자 둘까지"는
여기서 유도되는 결과입니다.

직접 유도해 보겠습니다. 두 전자를 같은 오비탈
{{< katex >}}\psi_a{{< /katex >}} 에 같은 스핀
{{< katex >}}\alpha{{< /katex >}} 로 넣으면

{{< katex display=true >}}
\Psi(1,2) = \psi_a(1)\alpha(1)\,\psi_a(2)\alpha(2)
{{< /katex >}}

입니다. 1 과 2 를 맞바꿔 보면 정확히 같은 식이 나옵니다.

{{< katex display=true >}}
\Psi(2,1) = \psi_a(2)\alpha(2)\,\psi_a(1)\alpha(1) = \Psi(1,2)
{{< /katex >}}

그런데 반대칭 조건은
{{< katex >}}\Psi(1,2) = -\Psi(2,1){{< /katex >}} 를 요구합니다. 둘을 함께
쓰면

{{< katex display=true >}}
\Psi = -\Psi \qquad \Longrightarrow \qquad \Psi = 0
{{< /katex >}}

그런 상태는 존재하지 않습니다. 그래서 한 오비탈에 들어갈 수 있는 전자는
최대 둘이고, 그 둘은 스핀이 반대여야 합니다.

이 하나의 부호가 주기율표 전체를 만듭니다. 만약 전자가 대칭 파동함수를
가졌다면 모든 전자가 1s 로 떨어져 화학이 존재하지 않았을 것입니다.

## 가림과 유효 핵전하

이제 근사를 정량화해 보겠습니다. 다전자 원자의 전자 하나가 실제로 느끼는
핵의 끌림은 {{< katex >}}Z{{< /katex >}} 그대로가 아닙니다. 다른 전자들이
사이에 끼어 핵전하를 **가리기**(shielding) 때문입니다.

이것을 보정 하나로 흡수합니다.

{{< katex display=true >}}
\boxed{\;Z_{\mathrm{eff}} = Z - \sigma\;}
{{< /katex >}}

{{< katex >}}\sigma{{< /katex >}} 를 가림 상수라 합니다. 그러면 수소에서
얻은 에너지 식을 거의 그대로 쓸 수 있습니다.

{{< katex display=true >}}
E_{n,l} \approx -13.6\ \mathrm{eV}\cdot\frac{Z_{\mathrm{eff}}^2}{n^2}
{{< /katex >}}

## 침투: 겹침이 깨지는 이유

{{< katex >}}Z_{\mathrm{eff}}{{< /katex >}} 는
{{< katex >}}l{{< /katex >}} 에 따라 다릅니다.

이유는 [수소꼴 원자]({{< ref "hydrogen.md" >}})의 원심력 장벽에 있습니다.

{{< katex display=true >}}
\frac{l(l+1)\hbar^2}{2\mu r^2}
{{< /katex >}}

{{< katex >}}l = 0{{< /katex >}} 이면 이 항이 0 이라 장벽이 없고,
{{< katex >}}s{{< /katex >}} 전자는 핵 근처까지 들어갈 수 있습니다. 방사방향
분포함수를 그려 보면 3s 오비탈은 바깥의 큰 봉우리 말고도 핵 가까이에 작은
봉우리를 갖습니다. 3p 는 그 안쪽 봉우리가 더 약하고, 3d 는 거의 없습니다.

이 "핵 근처까지 들어가는 정도"를 **침투**(penetration)라 하며, 순서는

{{< katex display=true >}}
s > p > d > f
{{< /katex >}}

입니다. 그리고 다음과 같이 논리가 이어집니다.

{{< katex display=true >}}
\text{침투 큼} \Rightarrow \text{가림 덜 받음} \Rightarrow Z_{\mathrm{eff}} \text{ 큼}
\Rightarrow \text{에너지 낮음}
{{< /katex >}}

따라서 같은 {{< katex >}}n{{< /katex >}} 안에서

{{< katex display=true >}}
\boxed{\;E(ns) < E(np) < E(nd) < E(nf)\;}
{{< /katex >}}

수소에서 우연히 겹쳐 있던 것이 여기서 풀립니다. 수소의
{{< katex >}}2s{{< /katex >}} 와 {{< katex >}}2p{{< /katex >}} 는 에너지가
같았는데, 전자가 하나뿐이라 가릴 것이 없었기 때문입니다. 전자가 둘 이상이면
가림이 생기고, 가림이 {{< katex >}}l{{< /katex >}} 에 따라 다르므로 겹침이
깨집니다.

화학은 이 깨짐 위에 서 있습니다. 겹침이 유지되었다면 같은 껍질의 오비탈이 모두
같은 에너지라 전자배치에 순서가 없었을 것이고, 주기율표에 족(group)이라는
구조도 없었을 것입니다.

## 쌓음 원리와 4s/3d 문제

전자를 낮은 오비탈부터 채워 나가는 것을 **쌓음 원리**(Aufbau principle)라
합니다. 순서는 위의 갈라짐이 정합니다.

{{< katex display=true >}}
1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < \dots
{{< /katex >}}

{{< katex >}}4s{{< /katex >}} 가 {{< katex >}}3d{{< /katex >}} 보다 먼저
오는 것이 눈에 띕니다. 주양자수가 더 큰데 에너지는 더 낮습니다.

이상해 보이지만 침투로 설명됩니다. {{< katex >}}4s{{< /katex >}} 는
{{< katex >}}l=0{{< /katex >}} 이라 장벽이 없어 안쪽 깊숙이까지 봉우리를 갖는
반면, {{< katex >}}3d{{< /katex >}} 는 {{< katex >}}l=2{{< /katex >}} 라
장벽이 높아 바깥에 머뭅니다. 평균 거리는 4s 가 멀지만 핵 가까이 다녀오는 몫이
있어 전체 에너지가 낮은 것입니다.

다만 이 순서가 늘 유지되지는 않습니다. 두 준위가 매우 가까워서 원소에 따라
뒤집히기도 합니다. Cr 이 {{< katex >}}[\mathrm{Ar}]4s^13d^5{{< /katex >}} 이고
Cu 가 {{< katex >}}[\mathrm{Ar}]4s^13d^{10}{{< /katex >}} 인 것이 그
예입니다. 반쯤 찬 껍질과 꽉 찬 껍질이 주는 안정화가 4s–3d 간격보다 크기
때문이며, 쌓음 원리는 법칙이라기보다 경향입니다.

## Hund 규칙

같은 에너지의 오비탈이 여럿 있을 때는 전자를 어떻게 넣을까요.

{{< katex display=true >}}
\text{스핀을 나란히 한 채 하나씩 따로 넣습니다.}
{{< /katex >}}

예를 들어 탄소의 {{< katex >}}2p^2{{< /katex >}} 는 한 오비탈에 둘을 짝지어
넣지 않고, 두 오비탈에 하나씩 같은 스핀으로 넣습니다.

이유는 다시 Pauli 원리입니다. 스핀이 같으면 파동함수의 공간 부분이 반대칭이어야
하는데, 반대칭 함수는 두 전자가 같은 위치에 있을 때 0 이 됩니다.

{{< katex display=true >}}
\Psi_{\text{공간}}(\mathbf{r},\mathbf{r}) = -\Psi_{\text{공간}}(\mathbf{r},\mathbf{r}) = 0
{{< /katex >}}

스핀이 나란한 두 전자는 서로 가까이 가지 않습니다. 이를 Fermi 구멍(Fermi
hole)이라 합니다. 멀리 떨어져 있으니 반발 에너지가 줄고, 그만큼 안정해집니다.

눈여겨볼 점은 이것이 자기적인 힘이 아니라는 것입니다. 스핀끼리의 자기
상호작용은 너무 약해서 이 효과를 낼 수 없습니다. Pauli 원리가 만든 공간적
회피가 정전기적 반발을 줄인 것이니, 순전히 대칭성의 결과입니다.

## 주기적 경향

이제 주기율표의 경향들이 두 요인의 경쟁으로 설명됩니다.

**한 주기를 따라 오른쪽으로 갈 때.** 핵전하 {{< katex >}}Z{{< /katex >}} 가
하나씩 늘고 전자도 하나씩 늡니다. 그런데 새로 들어오는 전자는 같은 껍질에
들어가므로 서로를 잘 가리지 못하고, 결과적으로
{{< katex >}}Z_{\mathrm{eff}}{{< /katex >}} 가 증가합니다.

{{< katex display=true >}}
Z_{\mathrm{eff}} \uparrow
\Rightarrow \text{원자 반지름} \downarrow,
\quad \text{이온화 에너지} \uparrow,
\quad \text{전자친화도} \uparrow
{{< /katex >}}

**한 족을 따라 아래로 갈 때.** {{< katex >}}n{{< /katex >}} 이 커지고 안쪽
껍질이 하나 더 생깁니다. 안쪽 껍질은 가림이 매우 효과적이라
{{< katex >}}Z_{\mathrm{eff}}{{< /katex >}} 는 별로 변하지 않는데
{{< katex >}}n{{< /katex >}} 은 확실히 커집니다.

{{< katex display=true >}}
n \uparrow
\Rightarrow \text{원자 반지름} \uparrow,
\quad \text{이온화 에너지} \downarrow
{{< /katex >}}

작은 예외들도 같은 논리로 설명됩니다. B 의 이온화 에너지가 Be 보다 낮은 것은
새 전자가 침투가 덜한 {{< katex >}}2p{{< /katex >}} 에 들어가기 때문이고,
O 가 N 보다 낮은 것은 {{< katex >}}2p^4{{< /katex >}} 에서 처음으로 한
오비탈에 전자가 짝지어져 반발이 커지기 때문입니다.

## 숫자로 확인하기

**리튬의 유효 핵전하.** Li 의 첫 이온화 에너지는 5.39 eV 입니다. 떨어져 나가는
것은 {{< katex >}}2s{{< /katex >}} 전자이므로
{{< katex >}}n=2{{< /katex >}} 로 두면

{{< katex display=true >}}
5.39 = 13.6\cdot\frac{Z_{\mathrm{eff}}^2}{2^2}
\qquad \Longrightarrow \qquad
Z_{\mathrm{eff}} = \sqrt{\frac{4\times5.39}{13.6}} = 1.26
{{< /katex >}}

핵전하는 3 인데 바깥 전자가 느끼는 것은 1.26 입니다. 안쪽
{{< katex >}}1s^2{{< /katex >}} 두 전자가
{{< katex >}}\sigma = 1.74{{< /katex >}} 만큼 가리는 셈입니다.

이 숫자가 말해 주는 것이 있습니다. 완벽한 가림이라면
{{< katex >}}\sigma = 2{{< /katex >}} 여서
{{< katex >}}Z_{\mathrm{eff}} = 1{{< /katex >}} 이 되었을 텐데, 실제로는
1.26 입니다. {{< katex >}}2s{{< /katex >}} 전자가 안쪽 껍질을 뚫고 들어가
핵을 직접 느끼는 몫이 있다는 뜻이고, 침투가 숫자로 나타난 것입니다.

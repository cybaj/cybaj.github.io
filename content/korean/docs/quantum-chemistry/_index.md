1900년 무렵의 물리학은 잘 굴러가고 있었습니다. 뉴턴 역학은 행성의 궤도를
맞혔고, Maxwell 방정식은 빛이 전자기파임을 밝혔으며, 통계역학은 기체의 성질을
설명했습니다. 남은 문제는 몇 개 되지 않아 보였는데, 그 몇 개가 고전물리학으로는
끝내 풀리지 않아 결국 새로운 역학이 필요해졌습니다.

## 다섯 번의 어긋남

고전물리학이 예측한 것과 실험이 실제로 보여 준 것을 나란히 놓으면
다음과 같습니다.
(개인 노트: 1장 양자역학의 기원)

| 고전적 예측 | 실제 관측 |
|---|---|
| 뜨거운 물체는 짧은 파장에서 무한한 에너지를 방출해야 합니다 | 어떤 파장에서 최대가 되고 짧은 파장에서는 0 으로 줄어듭니다 |
| 원자는 어떤 에너지든 가질 수 있으므로 연속 스펙트럼이 나와야 합니다 | 정해진 파장의 선만 나옵니다 |
| 빛이 파동이라면 세기가 셀수록 튀어나온 전자가 빨라야 합니다 | 전자의 운동에너지는 세기가 아니라 진동수가 정합니다 |
| 전자는 입자이므로 정해진 궤적을 그려야 합니다 | 전자도 회절하고 간섭합니다 |
| 위치와 속도는 원리적으로 동시에 정확히 알 수 있어야 합니다 | 둘을 함께 좁힐 수 없습니다 |

다섯 줄이 서로 다른 실험처럼 보이지만 사실은 하나의 이야기입니다. 에너지도
각운동량도 연속적인 양이 아니며, 물질도 빛도 입자와 파동 중 어느 한쪽이
아닙니다.

## 문서 구성

**실험이 요구한 것**

- **[양자 가설]({{< ref "origins.md" >}})** — 흑체 복사, Rayleigh–Jeans 의
  실패, Planck 분포, 광전효과, de Broglie, 불확정성. 고전역학이 어디서
  어긋났는지를 봅니다.

**대신할 기술**

- **[파동함수와 Schrödinger 방정식]({{< ref "wavefunction.md" >}})** — 궤적을
  버리고 파동함수를 얻습니다. 고유값 문제, Born 해석, 정규화, 파동함수가
  만족해야 할 네 조건.

**풀리는 세 문제** — 경계조건이 양자화를 만드는 세 가지 방식입니다.

- **[상자 속 입자]({{< ref "particle-in-a-box.md" >}})** — 벽에 갇힐 때.
  영점에너지, 겹침, 대응원리, 그리고 염료의 색.
- **[조화 진동자]({{< ref "oscillator.md" >}})** — 용수철에 묶일 때. 평형
  근처의 모든 퍼텐셜이 왜 포물선인지, 그리고 결합이 절대영도에서도 떠는 이유.
- **[회전 운동과 각운동량]({{< ref "rotation.md" >}})** — 한 바퀴 돌아 제자리로
  올 때. 벽이 없는데도 양자화되며, 오비탈의 모양이 여기서 결정됩니다.

**원자**

- **[수소꼴 원자]({{< ref "hydrogen.md" >}})** — Coulomb 퍼텐셜을 넣으면 Rydberg
  식이 유도됩니다. 세 양자수와 오비탈.
- **[다전자 원자]({{< ref "many-electron.md" >}})** — 전자가 둘만 되어도 정확히
  풀리지 않습니다. 오비탈 근사, Pauli 원리, 가림과 침투, 주기율표.
- **[원자 스펙트럼]({{< ref "atomic-spectra.md" >}})** — 준위를 실험으로 읽는
  법. 선택 규칙, 단일항과 삼중항, 미세구조.

**분자**

- **[Born–Oppenheimer 근사]({{< ref "born-oppenheimer.md" >}})** — 핵과 전자를
  갈라놓습니다. 분자 퍼텐셜 에너지 곡면.
- **[Valence-Bond 이론]({{< ref "valence-bond.md" >}})** — 결합을 겹침으로
  봅니다.
  전자쌍, σ 와 π, 공명, 혼성화.
- **[분자 오비탈 이론]({{< ref "molecular-orbital.md" >}})** — 전자를 분자
  전체의 것으로 봅니다. LCAO, 결합 차수, 그리고 산소가 자석에 붙는 이유.
